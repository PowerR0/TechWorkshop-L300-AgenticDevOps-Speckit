# Task 02 - Install prerequisite software

## Introduction

{: .warning }
> A GitHub Codespace supplies the common tools. Skip the installation commands, but run the validation commands to confirm each tool. If your Codespace predates this setup, run **Codespaces: Rebuild Container** from the Command Palette first; see [Task 01]({% link docs/01_setup_development_environment/01_01.md %}).

## Description

Install the common software below on your local machine. Versions are the minimum or recommended releases; use an organization-approved newer supported release if your organization requires it.

| Software | Version / deployment target | Download / installation page | Validate installation |
|---|---|---|---|
| Git | Current maintained release | [Git downloads](https://git-scm.com/downloads) | `git --version` |
| Visual Studio Code | 1.145 Stable or later | [VS Code downloads](https://code.visualstudio.com/download) | `code --version`; open VS Code successfully |
| Python | 3.14.x recommended | [Python downloads](https://www.python.org/downloads/) | `python --version` (Windows) / `python3 --version` (macOS, Linux); confirm 3.14 |
| pip | Included with the approved Python installation | [pip installation guidance](https://pip.pypa.io/en/stable/installation/) | `python -m pip --version` (Windows) / `python3 -m pip --version` (macOS, Linux) |
| Microsoft Visual C++ v14 Redistributable (Windows only) | Current supported v14 release matching the Python/application architecture; keep an existing compatible installation | [Microsoft download options](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist) | Installed under Windows **Installed apps**; Spec Kit runs without missing-runtime DLL errors |
| Node.js | 22.x; patch compatible with the specified npm version | [Node.js downloads](https://nodejs.org/en/download/) | `node --version`; confirm Node.js 22 |
| npm | 11.19.x | [npm installation guidance](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) | `npm --version`; confirm npm 11.19 |
| GitHub Copilot app (optional) | 1.1.35 or later | [GitHub Copilot](https://github.com/features/copilot) | Version in the app **About** screen; sign in and send a test prompt |
| GitHub Copilot CLI (optional) | 1.0.108 Stable or later | [GitHub Copilot CLI releases](https://github.com/github/copilot-cli/releases) | `copilot --version`; run `copilot`, sign in, send a test prompt |
| Microsoft Edge, Chrome, or an organization-approved browser | Organization-approved, supported release | [Microsoft Edge downloads](https://www.microsoft.com/edge/download) | Open the browser and confirm GitHub is accessible |

After the common software is installed, install the Spec Kit Specify CLI with pip.

## Success Criteria

- Every required tool in the table passes its validation command.
- The Specify CLI is installed with pip and `specify version` runs.
- You can sign in to GitHub in your browser.

### 02: Install Visual Studio Code

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

{% capture windows %}
Download and install Visual Studio Code from the [official downloads page](https://code.visualstudio.com/download), or run:

```powershell
winget install -e --id Microsoft.VisualStudioCode
```

Enable the installer's **Add to PATH** option to use the `code` command.
{% endcapture %}
{% capture macos %}
Download and install Visual Studio Code from the [official downloads page](https://code.visualstudio.com/download). In the Command Palette, run **Shell Command: Install 'code' command in PATH** to enable the terminal command.
{% endcapture %}
{% capture linux %}
**GitHub Codespaces:** VS Code and the workshop extensions are already configured.

**Local Linux:** Install the appropriate package from the [official downloads page](https://code.visualstudio.com/download).
{% endcapture %}
{% include os-tabs.html id="vscode-install" label="Visual Studio Code installation" windows=windows macos=macos linux=linux %}

Open a new terminal and verify, then open VS Code to confirm that it starts:

```bash
code --version
```

Install the GitHub Copilot extensions from the Extensions Marketplace (`Ctrl+Shift+X`, or `Command+Shift+X` on macOS), or run:

```bash
code --install-extension GitHub.copilot
code --install-extension GitHub.copilot-chat
```

</details>

### 03: Install Python and pip

Python 3.14.x is recommended. pip is included with the Python installation.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

{% capture windows %}
```powershell
winget install -e --id Python.Python.3.14
```

Select **Add Python to PATH** if you use the installer from the [downloads page](https://www.python.org/downloads/). Open a new terminal and verify:

```powershell
python --version
python -m pip --version
```
{% endcapture %}
{% capture macos %}
```bash
brew install python@3.14
```

Follow Homebrew's printed PATH instructions, then verify:

```bash
python3 --version
python3 -m pip --version
```
{% endcapture %}
{% capture linux %}
**GitHub Codespaces:** Python is supplied by the container OS. Skip installation and verify it below.

**Local Linux (Debian/Ubuntu):**

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-pip python3-venv
```

Verify:

```bash
python3 --version
python3 -m pip --version
```
{% endcapture %}
{% include os-tabs.html id="python-install" label="Python and pip installation" windows=windows macos=macos linux=linux %}

Confirm that Python reports `3.14`. If your Linux distribution provides an older version, install Python 3.14 from the [downloads page](https://www.python.org/downloads/) or use an organization-approved release.

</details>

### 04: Install the Microsoft Visual C++ v14 Redistributable (Windows only)

Spec Kit and some Python packages need the Visual C++ runtime. Skip this task on macOS and Linux.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Open Windows **Settings > Apps > Installed apps** and search for **Microsoft Visual C++ 2015-2022 Redistributable**. If a compatible release matching your Python architecture (x64 or Arm64) is installed, keep it. Otherwise install it:

```powershell
winget install -e --id Microsoft.VCRedist.2015+.x64
```

For other architectures, use the [Microsoft download options](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

Verify that the redistributable appears under **Installed apps**. You will confirm that Spec Kit runs without missing-runtime DLL errors in the next task.

</details>

### 05: Install Node.js and npm

Use Node.js 22.x with npm 11.19.x. npm is included with Node.js.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

{% capture windows %}
Download a Windows installer for **Node.js 22.x** from the [official Node.js 22 release directory](https://nodejs.org/dist/latest-v22.x/), choosing the installer for your architecture.
{% endcapture %}
{% capture macos %}
```bash
brew install node@22
```

Follow Homebrew's printed instructions to add Node.js 22 to your `PATH`.
{% endcapture %}
{% capture linux %}
**GitHub Codespaces:** Node.js 22 and npm are already installed.

**Local Linux (Debian/Ubuntu via NodeSource):**

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
```
{% endcapture %}
{% include os-tabs.html id="node-install" label="Node.js installation" windows=windows macos=macos linux=linux %}

Open a new terminal and verify:

```bash
node --version
npm --version
```

Node.js should report `v22.x.x`. If npm is not 11.19.x, update it:

```bash
npm install -g npm@11.19
```

</details>

### 06: Install the Spec Kit Specify CLI with pip

The development container installs the Specify CLI automatically; local users must install it. Skip the install command in GitHub Codespaces. If your network requires a proxy or internal package registry, complete [Task 03]({% link docs/01_setup_development_environment/01_03.md %}) first.

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

With Git and Python available on your `PATH`, install the same Specify CLI release as the devcontainer:

{% capture windows %}
```powershell
python -m pip install "git+https://github.com/github/spec-kit.git@v1.2.6"
```
{% endcapture %}
{% capture macos %}
```bash
python3 -m pip install "git+https://github.com/github/spec-kit.git@v1.2.6"
```
{% endcapture %}
{% capture linux %}
**GitHub Codespaces:** The Specify CLI is already installed. Run the verification command below.

**Local Linux:**

```bash
python3 -m pip install "git+https://github.com/github/spec-kit.git@v1.2.6"
```
{% endcapture %}
{% include os-tabs.html id="specify-install" label="Specify CLI installation" windows=windows macos=macos linux=linux %}

If pip reports an externally managed environment, install into a virtual environment (`python3 -m venv .venv`) and activate it first. Open a new terminal and verify:

```bash
specify version
```

Installing the CLI does not initialize Spec Kit in your repository. You will initialize your workspace in Exercise 03.

</details>

### 07: Install GitHub Copilot CLI and the Copilot app (optional)

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Install GitHub Copilot CLI 1.0.108 or later from the [releases page](https://github.com/github/copilot-cli/releases), or with npm:

```bash
npm install -g @github/copilot
```

Verify, then run `copilot`, sign in with `/login` if prompted, and send a test prompt:

```bash
copilot --version
copilot
```

For the GitHub Copilot app (1.1.35 or later), install it from the [GitHub Copilot page](https://github.com/features/copilot), open **About** to check the version, sign in, and send a test prompt. An active Copilot subscription and an organization policy allowing these clients are required.

</details>

### 08: Confirm browser access

<details markdown="block">
<summary><strong>Expand this section to view the solution</strong></summary>

Use [Microsoft Edge](https://www.microsoft.com/edge/download), Chrome, or an organization-approved browser. Open it and confirm that [GitHub](https://github.com/) is accessible and that you can sign in.

{: .note }
> You need a personal GitHub account (not an enterprise managed account) to fork the repository.

</details>
